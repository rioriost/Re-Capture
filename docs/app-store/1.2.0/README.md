# Store screenshots for 1.2.0

Four original window captures, two per localization: Folders and Output.
Each is 1280 × 800 JPEG without alpha, captured on macOS 27 on 2026-09-21.

The native SettingsView ran in a temporary app-hosted fixture with synthetic
paths and isolated defaults. The processing controller was dormant. Capture used
the user-authorized macOS `screencapture` utility with the exact fixture window
ID, no shadow, and JPEG output. No pixel editing or generated UI was used.

The temporary fixture and logs remain in ignored `build/AppStore/` locally.
The UI is identical between builds 7 and 8. These images were uploaded to the
English (U.S.) and Japanese draft localizations; both saved previews were checked.
